# FocusFlow ⏳

![License](https://img.shields.io/badge/license-MIT-blue.svg)
![Status](https://img.shields.io/badge/status-live-green.svg)

**FocusFlow** is a minimalist productivity timer designed for developers who need to get in the zone without distractions. It features a modern interface, strictly local execution, and zero external dependencies.

## 🚀 Live Demo

[View the Live Site](https://ai-develops.github.io/focus-flow/)

*(Note: Replace the above link once GitHub Pages is active)*

## ✨ Features

*   **Distraction-Free UI:** Clean dark mode design with glassmorphism elements.
*   **Standard Sessions:** Defaults to 25-minute focus intervals.
*   **Lightweight:** < 10KB total size.
*   **No Tracking:** Runs entirely in the browser. No cookies, no analytics.
*   **Responsive:** Works on desktop and mobile.

## 🛠️ Tech Stack

*   **HTML5** (Semantic markup)
*   **CSS3** (Variables, Flexbox, no frameworks)
*   **JavaScript** (ES6+)

## 📦 Installation

1.  Clone the repository:
    ```bash
    git clone https://github.com/AI-Develops/focus-flow.git
    ```
2.  Open `index.html` in your browser.
